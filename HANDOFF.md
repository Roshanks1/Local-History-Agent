# Implementation handoff — 2026-09-06

## Current update: conversational assistant

The current pipeline is query interpretation → local article discovery → semantic retrieval → article/section expansion → budgeted evidence → grounded answer. Interactive sessions now maintain bounded recent context, support follow-up questions, and ask clarification when an event reference is unresolved. `/new` resets memory; `/debug` toggles local trace files. See `ARCHITECTURE.md` and the updated `README.md` for current behavior; older sections below describe earlier milestones.

Added `query_analysis.py`, `conversation_state.py`, `retrieval_expansion.py`, `timeline_utils.py`, `answer_context.py`, `retrieval_config.py`, `retrieval_config.json`, `evaluate_assistant.py`, and focused tests. Updated `history_ai.py`, `main.py`, `article_discovery.py`, and documentation. Existing extraction/chunking, embedding caches, fixed-index commands and original benchmark artifacts remain in place.

Validation: 36 unit tests pass, and the original benchmark corpus hash is unchanged. `artifacts/assistant-validation/` contains the current five-question retrieval comparison and six live conversational turns (three causal turns, two Defenestration turns, one timeline), with exact model contexts and readable transcripts.

On the five provisionally labeled fixed-index questions, raw title-enriched hit rate@1 is 60% versus expanded retrieval at 80%; hit rate@3 and @5 remain 100%. MRR@5 changes from 0.80 to approximately 0.867. Recall@5 falls from 49% to approximately 30.67%. Section diversity and deduplication trade raw labeled-chunk coverage for broader intent coverage; this is not a blanket retrieval-quality or factual-accuracy improvement. The small labels are incomplete and independently unreviewed. Revisit these weights on a larger held-out set before promoting a quality claim.

Timeline entries use source date text, preserve available precision, and are sorted in code after local structured generation. The system rejects unknown source labels and some descriptions containing conflicting years. It can still associate a reference date with the wrong event or generate unsupported descriptions. Coreference and article selection remain bounded heuristics. Token limits use an estimate, and conversation memory is not persisted across restarts.

## Measured results

Title enrichment increased development hit rate@1 from 20% to 60% and hit rate@3/@5 from 80% to 100%. Recall@5 increased from 48.33% to 49.00%. This is a five-question, provisionally labeled development comparison, not a 59-question accuracy claim. See `BASELINE.md` and the raw JSON artifacts.

| Model | Answers completed | Mean generation tokens/s | Mean wall seconds/answer |
|---|---:|---:|---:|
| Qwen3 8B | 5/5 | 37.72 | 8.22 |
| Qwen3 14B | 5/5 | 22.14 | 11.57 |

All ten answers finished normally without output-length truncation or unknown citation labels. Wall timing includes model loading, and these short runs do not substitute for a controlled throughput benchmark. Hardware/memory utilization was not measured in this run.

Qualitative evidence review found unsupported additions in 8B responses: conflating the Defenestration with replacement of the king, calling delayed garrison withdrawal the formal war ending, and converting military casualties to deaths. 14B avoided those particular errors, but its France answer still infers motives from later outcomes. Both models can repeat problematic source chronology. Keep 14B as the default; no automatic factual-accuracy score is claimed. `QWEN_REVIEW.json` records observations separately from the original model outputs.

The out-of-corpus lunar-colony question produced an explicit insufficient-evidence response. That is one smoke test, not comprehensive abstention evaluation.
